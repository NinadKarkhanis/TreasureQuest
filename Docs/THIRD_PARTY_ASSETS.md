# Third-party asset and license review

This upgrade does not transfer ownership of third-party assets to the project owner.
The original repository contains imported sprite, audio, Unity, Photon and leaderboard
packages. Refer to their included licenses and publishers' terms before redistribution.
Do not assume all imported artwork/sounds are MIT licensed just because the game's
original README refers to MIT. The included `LICENSE` in this pack covers new original
source code written for this upgrade, not unrelated third-party content.
